高CTR成功サムネ学習フォルダ
このフォルダに置いた画像は、サムネ生成のたびに自動的にAIへ参考画像として注入されます。
「実際にCTRが高かった成功サムネ」を蓄積していくと、AIが構図・色彩・文字スタイルなど全要素を学習し、生成される5案すべてに「成功要素」を反映させます。
---
仕組み（重要）
上限なし＋ランダム選出方式
このフォルダには 何枚でも画像を置けます（上限なし）。1回の生成では、ここから自動的に10枚を選んでAIに送ります。
選び方は 「新しい順80% + ランダム20%」：
```
[フォルダに30枚あった場合]
  ↓ ファイル更新日時で新しい順にソート
  [新→古に並ぶ30枚]
  ↓
  ★ 8枚 = 新しい上位8枚から（最新トレンド重視）
  ★ 2枚 = 残り22枚からランダム（過去の名作も時々混ぜる）
  ↓
  合計10枚をAIに送信
```
このロジックのメリット
✅ 画像をどんどん増やせる（古いものを消さなくていい）
✅ 直近のトレンドを優先的に学習（80%は新しいもの）
✅ 過去の名作も時々参照（20%でランダム混入）
✅ 長期的にはフォルダ内の全画像から学習される
✅ 動作が常に安定（毎回10枚なのでレイテンシが一定）
---
配置ルール
ファイル形式
`.jpg` / `.jpeg` / `.png` / `.webp` のいずれか
ファイルサイズ
1枚あたり 2MB 以下を強く推奨
推奨解像度：1280×720 〜 1920×1080
ファイル名: 何でもOK（拡張子だけ守る）
推奨命名規則
ファイル名でいつ追加されたか分かるように、日付プレフィックスを推奨：
```
2026-01-15-business-killer.jpg
2026-02-03-ed-hotword.jpg
2026-04-22-yen-yasu.jpg
```
→ ただし、システムは ファイル更新日時 で新旧を判定するので、ファイル名は本質的には自由です。
枚数
0枚: 学習機能オフ（通常生成）
1〜10枚: 全枚数が毎回送られる
10枚超: ロジックに従って毎回10枚が選ばれる
理論上の上限なし（1000枚でもOK、選出が動く）

入れ替え方法（GitHub Web UI）
新しい画像を追加
https://github.com/binarykannai-bit/thumbnail-forge/tree/main/public/training を開く
緑の 「Add file」 → 「Upload files」
画像ファイルをドラッグ&ドロップ（複数まとめてOK）

→ 自動再デプロイ後、すぐに学習対象に加わります。
古い画像を削除（任意）
通常は削除する必要はありません（増えていくほど学習精度UP）。
ただし、明らかに失敗作・もう参考にしたくない画像があれば：
削除したい画像をクリック
右上 「・・・」 → 「Delete file」
「Commit changes」
---
どんな画像を選ぶべきか
良い学習素材
✅ 自分が運営するチャンネルで CTR 6%以上 を出したサムネ
✅ 競合チャンネルで 明らかに伸びている 動画のサムネ
✅ 同じジャンル内で デザイン的に優秀 と感じるサムネ
✅ 文字配置・色使い・構図がはっきりしている
避けたい素材
❌ ブレている / 解像度が低い画像
❌ 著作権侵害になりかねない他社の派手なロゴ・キャラクター
❌ ジャンルが大きく違うサムネ（例: ゲーム実況系のサムネをビジネス系に使う）
古いサムネは消すべき？
消す必要なし — 古いサムネも20%枠でランダムに混ざるので、過去の名作要素も学習に活きます。むしろ蓄積するほど学習プールが豊かになります。
ただし「もうこのスタイルは古い」「使いたくない」と感じるものは削除してOKです。
---
学習される要素（全て）
AIは以下の要素を選出された10枚から抽出して、5つの新しいサムネ案すべてに反映させます：
構図・レイアウトパターン
メインカラー・アクセントカラーの組合せ
文字の太さ・縁取り・影の付け方
表情・ポーズ（人物がいる場合）
矢印・吹き出し・記号などの装飾
全体トーン（緊張感・カジュアルさ等）
詳細は `lib/prompts.ts` の `trainingSection` を参照してください。
---
動作確認方法
サムネ生成後、Vercelログで以下のような行が出ていれば学習が動作中：
```
[training] pool=42, selected=10: 2026-04-22-latest.jpg, 2026-04-15-x.jpg, ...
```
`pool` が現在のフォルダ内画像枚数、`selected` が今回送られた画像名です。

設定変更（高度）
`app/api/generate/route.ts` の冒頭に以下の定数があります：
```typescript
const TRAINING_PER_REQUEST = 10;  // 1回の送信枚数
```
この数値を変えれば、1回あたりの学習画像数を調整できます：
`5` → 速度優先（5枚）
`10` → デフォルト（バランス）
`15` → 学習精度優先（15枚、応答時間+5秒）
`20` → 最大学習（20枚、タイムアウトリスク）
20枚を超えると Vercel の60秒制限に引っかかる可能性があるので、ご注意ください。
